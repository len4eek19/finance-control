    Подключение к локальной базе…

    Telegram бот

    Отправляйте выписки и расходы прямо в группу

    Локальный режим (бот на этом компьютере)
    1. В @BotFather: /newbot → скопируй токен в data/bot.json → "token"
    2. Запусти Запустить бота.cmd
    3. Добавь бота в группу Telegram
    4. В BotFather: /mybots → Bot Settings → Group Privacy → Disable
    5. Отправляй CSV-выписки или пиши расходы через /add
    Облачный режим (бот работает 24/7 без компьютера)
    1. Загрузи проект на GitHub
    2. Зайди на railway.app → New Project → Deploy from GitHub → выбери репо
    3. В Variables добавь:
      BOT_TOKEN — токен от @BotFather
      ALLOWED_CHAT_IDS — ID группы (например -123456789)
      API_KEY — любой случайный секрет (например openssl rand -hex 16)
    4. После деплоя скопируй URL сервиса (вида https://…railway.app)
    5. Вставь в data/bot.json:
      "cloud_bot_url": "https://…railway.app"
      "cloud_sync_key": "тот же API_KEY"

    Как приложение считает деньги

    • Положительные операции — доходы; расходы с MCC 4829 без парной операции помечаются для проверки.
    • Снятие наличных попадает в кошелёк наличных, а не в структуру расходов.
    • Ручная категория всегда приоритетнее автоматического правила.
