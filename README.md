# Мої гроші — локальный контроль трат

Запустите `Запустить приложение.cmd`. Приложение откроется в браузере, но все финансовые данные будут храниться в локальной SQLite-базе `data/finance.db` рядом с программой. Сервер доступен только на `127.0.0.1` и не передаёт выписки в интернет.

## Что есть в MVP

- mono-inspired интерфейс: чёрные поверхности, лимонный акцент и крупные суммы;
- импорт нескольких CSV-выписок Monobank/совместимого формата;
- локальная SQLite-база с индексами для дат, MCC, счетов и категорий;
- защита от повторного импорта в рамках выбранного источника;
- конвертация EUR, BGN, UAH и USD в базовую валюту EUR;
- категории, ручная корректировка и очередь для переводов, которые нельзя безопасно считать внутренними;
- наличный кошелёк и единая форма ручного добавления расходов, доходов и переводов;
- дашборд финансового цикла с 10-го по 9-е, недельные лимиты, структура трат и рекомендации;
- календарь обязательных платежей (электричество, вода и интернет — 25-го числа), резервная копия JSON и удаление локальных данных;
- отдельный экран недели: дневной ориентир, конверты продуктов/кафе, перенос лимитов и список покупок с прогнозом корзины.

## Первый запуск

1. Дважды щёлкните `Запустить приложение.cmd` и дождитесь открытия приложения.
2. Нажмите «Импорт выписок».
3. Выберите один или несколько CSV-файлов.
4. Для одного файла при желании укажите имя счёта; для нескольких каждый файл станет отдельным источником.
5. Откройте «Настройки» и при необходимости скорректируйте бюджет и исторические курсы UAH/EUR, USD/EUR.

В CSV с MCC 4829 исходящий перевод не считается расходом автоматически: приложение попытается сопоставить его с входящей операцией другого вашего источника в пределах пяти минут. Несопоставленные переводы остаются в разделе «Проверить», где их можно вручную отнести к категории.

## Безопасность локального Telegram-бота

Файл `data/bot.json` содержит токен Telegram и список разрешённых чатов. Он создаётся только для локального запуска и исключён из Git. Не отправляйте этот файл в репозитории или третьим лицам.
